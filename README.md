Mi Tienda - E-Commerce Landing Page
Una interfaz de usuario (UI) para una tienda en línea construida desde cero. Este proyecto demuestra fundamentos sólidos en maquetación web moderna, priorizando la velocidad, el diseño limpio y la adaptabilidad sin depender de frameworks pesados.

Lo más destacado del proyecto
-Arquitectura CSS Grid: Layout bidimensional estructurado asimétricamente (2fr / 1fr) para organizar eficientemente el catálogo y las promociones.

-100% Responsivo: Implementación de @media queries que transforma la cuadrícula a una sola columna en pantallas pequeñas (<768px). Listo para móviles.

-Diseño UI/UX Pulido: Estilo visual moderno basado en tarjetas ("cards") con sombras sutiles (box-shadow), bordes redondeados y botones con estados interactivos (hover).

-HTML Semántico: Uso de etiquetas modernas (<main>, <section>, <header>) para mejorar la accesibilidad y la estructura del código.

Tecnologías
-HTML5
-CSS3 

Cómo visualizarlo
¡Cero dependencias! Solo clona el repositorio o descarga los archivos y abre el archivo index.html en cualquier navegador web.
